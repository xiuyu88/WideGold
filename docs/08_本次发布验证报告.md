## 7. 发布前仍建议在 GitHub/目标机执行

GitHub Actions 会重新执行 Python 测试与前端构建。目标 Docker 主机建议：

```powershell
.\scripts\quickstart.ps1
.\scripts\quicktest.ps1
```

如需真实 LLM 测试，再单独执行：

```powershell
.\scripts\docker-e2e.ps1 -Analysis
```

该步骤会消耗模型 Token，不属于默认 CI。
