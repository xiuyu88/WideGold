# 宽基 + 黄金因子体系与影响准则 V1

> **用途**：WideGold Agent 的研究准则内核、评分引擎配置基线、数据采集需求基线与后续动态更新规范。  
> **适用资产**：沪深300、中证A500、中证500、中证1000、创业板指、科创50、人民币黄金。  
> **版本定位**：V1 是“可解释、可工程化、可回测”的研究先验，不是已经由历史样本估计得到的最终参数。本文所有初始敏感度、阈值、权重上限均应视为 **engineering priors（工程先验）**，上线前和上线后都必须通过 point-in-time 回测、滚动验证与人工审核持续校准。  
> **产品原则**：系统输出“市场环境支持度 + 信心 + 主要证据 + 风险”，不把任何单个因子写成必然涨跌规则，也不构成投资建议。

---

## 0. V1 核心结论

WideGold Agent 的判断内核建议拆成四层，而不是“新闻 → LLM → 买卖”：

```text
原始数据 / 官方公告 / 新闻
            ↓
      Indicator / Event
            ↓
        Factor State
        [-100, +100]
            ↓
 Asset-Factor Sensitivity
 + 冲突 / 去重 / 时效规则
            ↓
      Asset Direction Score
            ↓
      Asset Score 0~100
      + Confidence 0~100
            ↓
       小白化解释 / Dashboard
```

V1 对 A 股宽基采用 **15 个核心因子**，对黄金采用 **12 个核心因子**。因子不是一条指标，而是一个“经济含义稳定、可以被多个指标观测”的研究对象。例如“国内资金面流动性”由 DR007、回购利差、资金波动等共同刻画，而不是把央行单日净投放机械等同为利多。

V1 的关键设计约束如下：

1. **同一因素不能重复计分。** 美联储鸽派、实际利率下降、美元走弱高度相关，黄金模型不能简单三次满额相加。
2. **方向必须有语义。** 统一规定 `factor_state > 0` 代表“对该资产族当前环境更支持”，避免不同因子正负方向混乱。
3. **宏观数据必须保存发布时点和历史版本。** 回测不能用后来修订的数据替代当时市场能看到的数据。
4. **事件必须衰减。** 新闻和政策冲击不应永久留在评分中；当真实利率、汇率、信用等观测变量已经体现该事件时，应逐步由“事件分”切换为“状态分”。
5. **便宜不等于马上涨。** 估值属于中长期支撑因子，不作为 1～5 日择时的强触发器。
6. **宽松不等于所有宽基同步上涨。** 中国股票市场中货币政策—流动性的影响存在时变和市场状态差异，且小中盘/民企在特定流动性政策冲击下反应可能更强。[^8][^9]
7. **通胀上升不等于黄金必涨。** 通胀必须和实际利率、美元、增长/衰退风险、投资需求联动判断；World Gold Council 2026 年研究也明确指出通胀再起本身并不足以推出黄金大涨。[^19]
8. **黄金必须拆成全球核心与人民币覆盖层。** 对中国用户，人民币黄金收益不仅受美元金价影响，还受 USD/CNY 和国内基差/溢价影响。
9. **V1 不启用自动在线改权。** 允许系统统计因子有效性并生成调权建议，但生产权重变更必须经过滚动验证和版本审批。
10. **模型不替代规则。** LLM 负责事件理解、因子映射、原因标签与解释；确定性代码负责计算最终分值。

# 1. 资产定义与结构暴露

## 1.1 为什么先固定资产“身份”

宽基指数不是名字不同但逻辑相同的几个篮子。指数编制规则本身决定了其结构暴露，因此资产敏感度矩阵必须以官方编制方法为第一层约束。

### 沪深300（CSI300）

V1 定位：**A 股大盘核心 / 高流动性 / 权重股代表**。

工程含义：

- 对大盘盈利、宏观增长、估值/ERP、机构资金和外部金融条件较敏感；
- 相较小盘，单纯“流动性弹性”不应预设为最高；
- 大盘指数并不等同于金融/消费等固定行业组合，实际行业暴露必须动态读取成份权重，不能写死。

### 中证A500（CSI A500）

中证指数官方编制方案明确：A500 从各行业选取市值较大、流动性较好的 500 只证券；候选证券需满足一定市值、互联互通资格等条件，并使一级行业自由流通市值分布尽可能接近样本空间；单只样本权重不超过 10%，前五大样本合计不超过 40%。[^1]

V1 定位：**行业相对均衡的核心宽基 / 大中盘综合代表 / 高可投资性**。

工程含义：

- 不应简单视为“沪深300扩大版”；
- 行业政策冲击的表现更需要结合实时行业权重；
- 外资/互联互通相关信息具有较高结构相关性，但 2024 年 8 月 19 日后官方已不再披露沪深股通实时买卖成交额和净流向，因此工程上不得继续依赖旧式“每日北向净买入”字段。[^16]

### 中证500（CSI500）

中证指数官方方案将其称为“中证小盘500指数”：先剔除沪深300样本及过去一年日均总市值前300的证券，再剔除剩余证券中日均成交金额后20%，最后按日均总市值选取前500。[^2]

V1 定位：**沪深300之外的中小盘核心代表**。

工程含义：

- 对信用、资金面、风险偏好和市场流动性变化的敏感度应高于沪深300的先验；
- 对盈利周期同样敏感，不能只用“流动性驱动”解释；
- 与中证1000之间的区别应主要通过规模/成份暴露动态数据校正，而不是写死行业印象。

### 中证1000（CSI1000）

现行基金披露材料基于标的指数规则，将中证1000描述为：在全部 A 股中剔除中证800成份股后，由规模偏小且流动性较好的1000只股票组成，代表一批小市值公司。[^3]

V1 定位：**小盘 / 高弹性 / 风险偏好与资金环境敏感**。

工程含义：

- 对资金面、信用条件、杠杆资金、市场广度、风险偏好有较高先验敏感度；
- 但不能把“小盘因子”写成永久正收益规律。中国 A 股异常研究显示，价值、风险与交易类异常较稳定，而规模、质量、过去收益等类别的证据整体更弱。[^11]
- 因此“中证1000更受流动性影响”可以作为先验，但“长期小盘必胜”不能进入准则库。

### 创业板指（ChiNext）

官方编制方案定位创业板指数为反映创业板运行特征、表征中国创新创业企业的业绩基准；样本数量为100只，并基于市值、成交等规则筛选。2025 年修订后又引入 ESG 负面剔除，并将单只样本权重上限调整为20%。[^4][^5]

V1 定位：**创新成长 / 高久期 / 高风险偏好暴露**。

工程含义：

- 对折现率、全球成长估值、国内流动性、风险偏好和盈利预期变化具有较高敏感度；
- 不应将其静态等同于某个行业；实际行业和龙头集中度随调样变化。

### 科创50（STAR50）

上海证券交易所将科创50定位为科创板首条反映板块证券价格表现的指数，选取市值大、流动性好的代表性证券；科创板本身重点服务新一代信息技术、生物医药、高端装备等战略新兴与高新技术产业。[^6]

V1 定位：**高研发 / 高科技 / 高久期 / 高波动成长代表**。

工程含义：

- 对实际/名义折现率、全球科技风险偏好、产业政策和盈利预期高度敏感；
- 行业政策事件允许资产级 override，但必须结合最新成份权重验证。

### 人民币黄金（RMB Gold）

面向国内普通用户，默认输出“人民币黄金环境评分”，而不是只输出美元黄金。

近似价格分解：

$
P^{CNY}_{gold}
\approx
P^{USD}_{gold}
\times USD/CNY
\times UnitConversion
+
LocalBasis
$

对数收益近似：

$
r^{CNY}_{gold}
\approx
r^{USD}_{gold}
+
\Delta \ln(USD/CNY)
+
\Delta Basis
$

因此 V1 必须形成：

```text
Global Gold Core
  ├─ US real yield
  ├─ USD
  ├─ Fed surprise
  ├─ risk & uncertainty
  ├─ inflation regime
  ├─ central-bank demand
  ├─ global ETF flow
  ├─ CFTC positioning
  └─ global momentum
           +
China / RMB Overlay
  ├─ USD/CNY translation
  └─ SGE price / premium / physical demand proxy
```

上海黄金交易所可提供 Au99.99 等每日行情以及上海金基准价，为国内覆盖层提供官方价格和交易数据。[^25][^26]

# 2. 因子体系设计规范

## 2.1 因子不是指标

以下三者必须分开：

```text
Indicator（指标）
    ↓
Factor（经济含义）
    ↓
Asset Impact（资产影响）
```

例如：

```text
DR007
R001-DR001
回购成交与波动
       ↓
EQ01 国内资金面流动性
       ↓
沪深300 +2
中证1000 +4
创业板 +4
```

这样做的原因是数据源和具体指标可以变化，而因子的经济含义应该尽可能稳定。

---

## 2.2 统一状态定义

每个因子输出：

```text
factor_state ∈ [-100, +100]
```

统一语义：

- `+100`：极强支持当前资产族；
- `+50`：明显支持；
- `0`：中性 / 无有效信息；
- `-50`：明显压制；
- `-100`：极强压制。

注意：

> “正负”描述的是**资产支持度**，而不是原始指标自身的涨跌。

例如黄金实际利率因子：

```text
实际利率快速下降
→ G01_US_REAL_YIELD = +80

实际利率快速上升
→ G01_US_REAL_YIELD = -80
```

---

## 2.3 三个判断周期

| 周期 | 目标 | 典型因子 |
|---|---|---|
| Tactical | 1～5 个交易日 | 事件、资金、广度、风险情绪、短期趋势 |
| Swing | 1～4 周 | 利率、汇率、信用、宏观 surprise、盈利修正 |
| Strategic | 1～6 个月 | 盈利/利润周期、估值、信用周期、央行黄金需求 |

V1 Dashboard 可先输出一个综合分，但内部必须保留三个 horizon 子分，避免将“短期过热”和“中长期便宜”硬塞进一个语义中。

---

## 2.4 证据等级

### Evidence Grade

| 等级 | 含义 | 生产使用 |
|---|---|---|
| A | 官方定义/数据 + 较稳定经济机制，或多篇高质量研究支持 | 核心因子 |
| B | 有同行评审或可靠机构证据，但明显受时期/状态影响 | 核心因子，但需条件/上限 |
| C | 机制合理但证据不稳定或数据代理较弱 | 辅助/战术修正 |
| D | LLM/研究流程新发现、尚未验证 | 仅 shadow，不进入生产分 |

### Source Tier

| Tier | 来源 | 建议基础可信度 |
|---|---|---:|
| S | 央行、统计局、交易所、指数公司、监管机构 | 1.00 |
| A | 原始同行评审论文 / 高质量数据库 | 0.90 |
| B | 可靠国际机构、券商/基金研究、行业协会 | 0.75 |
| C | 主流财经媒体 | 0.55 |
| D | 自媒体、社交媒体、匿名爆料 | 0.00～0.30 |

**D 级消息默认不得进入生产评分，只进入 watchlist。**

# 3. A 股宽基核心因子库

V1 建议 15 个因子，分为 6 个簇。簇的目的不仅是分类，更用于 **防重复计分（group cap）**。

```text
A. 国内货币信用
EQ01 资金面流动性
EQ02 信用与货币扩张
EQ03 折现率环境

B. 宏观与盈利
EQ04 增长动能
EQ05 价格—利润周期
EQ06 指数盈利与盈利修正

C. 估值与政策
EQ07 估值与股权风险溢价
EQ08 政策支持

D. 外部环境
EQ09 人民币与外部平衡
EQ10 全球金融条件

E. 资金
EQ11 外资活动
EQ12 国内资金与杠杆

F. 市场状态
EQ13 市场广度与交易流动性
EQ14 趋势与动量
EQ15 风险偏好、情绪与波动
```

---

## EQ01 — CN Funding Liquidity｜国内资金面流动性

**定义**：银行间短期资金的松紧程度，以及资金压力是否正在向资本市场传导。

**主要指标**

- DR007；
- DR007 相对政策利率/央行操作利率的利差；
- R001 - DR001、R007 - DR007；
- 回购利率波动；
- 质押式回购成交；
- 月末/季末/税期/春节等季节效应；
- OMO/MLF 等仅作为背景，不单独作为方向信号。

**正向状态**

- 资金利率持续处于相对宽松区间；
- 利差收窄；
- 资金波动下降；
- 流动性压力释放且市场广度/信用未恶化。

**负向状态**

- DR007 等显著偏离政策锚并持续走高；
- 非银资金明显更紧；
- 流动性压力和波动同步上升。

**影响逻辑**

改善资金面降低短期融资压力、提升杠杆与风险承担空间，但其对股票市场的传导具有状态依赖。研究显示中国货币政策对股市流动性的影响具有时间变化与牛熊非对称，宽松政策并非在任何情形下都能同样补充市场流动性。[^8] 疫情时期事件研究则发现流动性政策对股票市场具有较显著正向反应，且中小企业、民企反应更强。[^9]

**V1 结论**

- Evidence：A/B；
- Horizon：Tactical + Swing；
- Update：每日；
- Max age：1 个交易日；
- 小盘/成长敏感度高于大盘是 **B 级先验**，不能当成固定贝塔。

**冲突规则**

若资金宽松同时出现：

```text
EQ04 增长动能 << 0
AND
EQ06 盈利修正 << 0
AND / OR
信用压力显著
```

则不能把“低利率/资金宽松”直接解释成全面强利多，应降低 EQ01 贡献或 Confidence。

---

## EQ02 — CN Credit & Money｜信用与货币扩张

**定义**：实体经济信用创造和货币活化程度，而非银行间一天的资金松紧。

**主要指标**

- 社会融资规模存量增速；
- 社融增量及结构；
- 人民币贷款及企业中长期贷款；
- 信用脉冲（credit impulse）；
- M1 / M2 及其趋势；
- 企业存款、居民存款结构；
- 政府债融资需和私人信用区分。

**正向状态**

- 信用增速改善且结构由政府债单一支撑转向企业/居民有效融资改善；
- M1 活化趋势改善；
- 企业中长期信贷和融资需求改善。

**负向状态**

- 信用扩张持续减速；
- 总量看似上升但私人部门融资意愿弱；
- 货币增长与实体活跃度背离。

**重要数据口径规则**

人民银行自 2025 年 1 月统计起修订 M1 口径，将个人活期存款和非银行支付机构客户备付金等纳入。历史序列若混用新旧定义会产生伪信号，因此数据库必须保存 `definition_version`，回测时使用可比序列。[^15]

**V1 结论**

- Evidence：A/B；
- Horizon：Swing + Strategic；
- Update：月度；
- Max age：直到下一次官方发布，但需随新数据降低 stale risk；
- 不使用“单月社融高于去年 = 强利多”的简单规则，必须分解结构。

---

## EQ03 — CN Discount Rate｜国内折现率环境

**定义**：人民币无风险利率/长期融资价格对权益估值的支持程度。

**主要指标**

- 10Y 中国国债收益率；
- 2Y / 5Y / 10Y 曲线；
- 10Y - 1Y / 10Y - 2Y 曲线；
- AAA 信用债相对国债利差；
- 必要时构造通胀调整后的真实折现率代理。

中债收益率曲线由中央结算公司基于银行间与交易所报价、成交等信息编制并于每个工作日日终发布，可作为官方利率数据基线。[^14]

**关键语义**

本因子不是：

```text
国债收益率下降 = 股票必涨
```

而是：

```text
折现率下降所带来的估值支持
-
收益率下降所隐含的增长/通缩担忧
```

后一个渠道由 EQ04 / EQ05 / EQ06 捕捉。

**冲突规则**

若：

```text
10Y CGB 大幅下行
BUT
PMI / 盈利预期 / 信用同时明显恶化
```

则 EQ03 可以为正，但贡献上限下降，不允许它单独把成长资产推至高置信度强积极。

**V1 结论**

- Evidence：A/B；
- Horizon：Swing；
- Update：每日；
- Growth/STAR 敏感度高于 CSI300 是久期机制先验，需要回测确认。

---

## EQ04 — CN Growth Momentum｜国内增长动能

**定义**：真实经济活动的方向、速度和 surprise。

**主要指标**

- 制造业 PMI；
- PMI 新订单；
- 大/中/小企业 PMI；
- 非制造业 PMI；
- 工业增加值；
- 社零；
- 出口；
- 固定资产投资；
- 房地产相关需求数据；
- 高频生产/货运等作为辅助。

国家统计局 PMI 为月度、季调后的先行指标；50 是环比扩张/收缩分界，但工程上应同时使用趋势和 surprise，而非只用“>50 / <50”。[^12]

**推荐状态模型**

```text
growth_state =
0.45 * surprise_score
+ 0.35 * trend_score
+ 0.20 * level_score
```

这是 V1 模板参数，不是最终估计系数。

**方向**

- 增长改善：一般支持权益盈利与风险偏好；
- 增长恶化：压制企业盈利；
- 但增长过热可能通过利率/政策收紧产生反向折现压力，由 EQ03 / EQ10 抵消。

**V1 结论**

- Evidence：A；
- Horizon：Swing + Strategic；
- Update：月度 / 混合；
- 对 CSI300/A500/CSI500 的直接盈利敏感度先验较高；
- 对科技成长仍重要，但不能只看 GDP 总量，应结合盈利修正。

---

## EQ05 — Price-Profit Cycle｜价格—利润周期

**定义**：PPI/CPI、成本、库存和工业利润共同构成的企业利润环境。

**主要指标**

- PPI；
- CPI；
- PPI-CPI；
- 工业企业利润；
- 营业收入、利润率；
- 库存/产成品；
- 原材料价格；
- 行业利润分布。

国家统计局按月发布规模以上工业企业利润和相关经营指标，可用于企业利润周期观测。[^13]

**正向状态**

- 价格环境和需求改善推动收入/利润率修复；
- 利润增速/利润率改善具有一定广度；
- 库存与需求关系健康。

**负向状态**

- 通缩压力与需求疲弱压缩收入利润；
- 成本冲击上升但终端需求无法转嫁；
- 利润修复只集中于少数上游行业，而指数整体盈利未改善。

**V1 结论**

- Evidence：A/B；
- Horizon：Swing + Strategic；
- 必须结合指数成份行业暴露，不把 PPI 上升固定解释为所有指数利多。

---

## EQ06 — Index Earnings｜指数盈利与盈利修正

**定义**：指数成份股盈利水平、盈利增长和市场预期修正。

**主要指标**

- 指数 EPS TTM；
- 一致预期 EPS；
- FY1 / FY2 盈利增速；
- 盈利上调/下调公司比例；
- 净利润增速；
- ROE / 利润率；
- 行业盈利贡献。

中国市场研究表明，聚合盈利与股票收益的联系在更长时间区间上更清晰；这支持把盈利作为中期核心因子，而不是日内新闻因子。[^10]

**正向状态**

- EPS 增长和一致预期同步上修；
- 盈利扩散，而非只由极少数权重股贡献；
- 估值不因价格上涨过度透支。

**负向状态**

- 连续盈利下修；
- 利润增长集中、广度恶化；
- 价格上涨但盈利不跟随。

**V1 结论**

- Evidence：A；
- Horizon：Swing + Strategic；
- Update：若有机构一致预期可日更/周更；仅官方财报则低频；
- 对所有权益指数属于最高优先级核心因子之一。

---

## EQ07 — Valuation & ERP｜估值与股权风险溢价

**定义**：资产价格相对于盈利、净资产、现金流及无风险利率是否昂贵。

**主要指标**

- PE TTM / Forward PE；
- Earnings Yield；
- PB；
- Dividend Yield；
- ERP = Earnings Yield - Risk-Free Yield（可选多口径）；
- 历史分位；
- 横向资产相对估值。

中国因子研究表明，针对中国市场构造的价值因子中 earnings-price ratio 具有重要解释力，而简单照搬海外因子结构并不理想。[^7] 同时，股息率预测力会受到制度变化影响；研究发现中国市场 dividend-price ratio 的预测力在2008年之后明显弱化，因此不能把高股息率单独写成通用择时规则。[^17]

**规则**

- 估值越便宜 → **中长期期望回报支撑增加**；
- 估值便宜 ≠ 短期见底；
- 若盈利仍快速下修，便宜可能是“value trap”，Confidence 下调。

**V1 结论**

- Evidence：A/B；
- Horizon：Strategic 为主；
- Tactical 权重严格封顶；
- 不允许估值单因子触发“强势偏积极”。

---

## EQ08 — Policy Support｜政策支持

**定义**：货币、财政、资本市场、地产、产业政策等官方政策对经济/盈利/风险偏好的边际影响。

**事件字段必须包括**

```text
policy_scope
target_assets_or_industries
official_level
implementation_status
funding_or_scale
novelty
expected_vs_surprise
effective_date
market_confirmation
```

**政策不是一个简单情绪因子。**

推荐拆解：

```text
PolicyImpact =
方向
× 强度
× 官方可信度
× 新颖度
× 落地程度
× 目标相关度
× 衰减
```

**实施状态 V1 先验**

| 状态 | implementation |
|---|---:|
| 未验证传闻 | 0（不进生产分） |
| 官方表态 / 指导意见 | 0.4～0.6 |
| 正式规则 / 预算 / 工具公布 | 0.7～0.9 |
| 资金或措施已执行 | 1.0 |

具体值均需配置化。

**风险**

经济政策不确定性研究显示，中国股票回报与政策不确定性创新存在负相关，且海外政策不确定性也可影响中国市场。[^18] 因此“政策新闻很多”并不等于利好；政策不确定性、反复与执行落差应进入 Confidence / Risk，而不是被正面新闻数量淹没。

**V1 结论**

- Evidence：B；
- Horizon：Tactical + Swing；
- `asset_override` 优先于固定矩阵；
- 同一政策事件不得被多个新闻重复计分。

---

## EQ09 — RMB & External Balance｜人民币与外部平衡

**定义**：人民币汇率及其背后原因对外资、风险偏好、出口竞争力和国内政策空间的综合影响。

**指标**

- USD/CNY；
- CFETS 人民币汇率指数；
- 汇率波动率；
- 外汇储备等低频辅助；
- 离岸/在岸价差；
- 出口、贸易条件。

**禁止静态方向**

人民币贬值可能：

```text
+ 出口竞争力
+ 国内宽松空间（视情境）
- 外资风险偏好
- 资本流动压力
- 风险溢价
```

因此必须附 `reason_tag`：

```text
policy_easing
growth_divergence
capital_outflow
trade_shock
risk_off
usd_strength
```

只有原因识别后才给资产影响。

**V1 结论**

- Evidence：B/C；
- Horizon：Tactical + Swing；
- 独立权重较低，更多与 EQ10、EQ11、出口行业暴露联动。

---

## EQ10 — Global Financial Conditions｜全球金融条件

**定义**：美国货币政策、美元、美债收益率、全球波动等通过金融、汇率和贸易渠道影响 A 股的外部环境。

**指标**

- Fed surprise / 政策预期变化；
- UST 2Y / 10Y；
- 10Y TIPS real yield；
- DXY；
- VIX；
- 全球股票风险环境；
- 信用利差。

研究识别了美国货币政策通过贸易、汇率和金融渠道向中国传导，金融渠道会影响中国企业长期融资溢价和利率预期。[^20] 更早的中国市场实证研究也发现宏观、流动性和美国金融压力与中国股票收益存在显著联系。[^21]

**正向语义**

```text
全球流动性/估值环境对风险资产更支持
```

例如美债实际利率下降、美元走弱、全球风险压力下降可能提高该因子，但需要区分“因全球衰退恐慌导致收益率暴跌”的情况。

**V1 结论**

- Evidence：A/B；
- Horizon：Tactical + Swing；
- 创业板/科创50先验敏感度最高；
- 与人民币因子、外资因子建立 correlation group，防止重复计分。

---

## EQ11 — Foreign Activity｜外资活动

**定义**：境外资金对 A 股的实际参与和持仓变化，作为战术确认因子。

研究显示沪深港通样本中外资净流入与 A 股回报正相关，且外资偏好高质量股票。[^22] 但这不代表流量是单向因果，也不意味着适合追涨。

**重要工程变化**

自 2024 年 8 月 19 日起，沪深股通官方披露机制调整：

- 不再披露实时买入/卖出成交金额；
- 收市后披露成交总额、总笔数、ETF成交总额、前十大活跃证券及成交总额；
- 单只证券沪深股通持有量改为季度披露。[^16]

因此 V1 **不得设计一个依赖“官方每日北向净买入金额”的核心字段**。

可采用：

- 沪深股通成交活跃度；
- 季度持仓变化；
- 获授权商业数据源的外资流代理（若未来购买）；
- A500/CSI300成份中的外资偏好与持仓暴露；
- 外资活动仅作为确认项。

**V1 结论**

- Evidence：B；
- Horizon：Tactical / Quarterly holding；
- CSI300/A500敏感度先验高于中证1000；
- 若无可靠方向性流量数据，则 `factor_state` 降权或置为 unavailable，不允许 LLM 猜。

---

## EQ12 — Domestic Flow & Leverage｜国内资金与杠杆

**定义**：ETF申赎、融资资金、机构资金等对指数的真实资金支持。

**指标**

- 指数 ETF 份额变化；
- ETF 估算净申赎；
- 融资余额、融资买入额；
- 公募/保险等可获得的低频资金代理；
- 成交额与资金行为组合。

上交所每日披露融资融券汇总和明细，可作为杠杆资金的官方数据源之一。[^23]

**关键规则**

- ETF“成交额”不等于净流入；
- ETF价格上涨导致资产规模增加不等于申购；
- 必须优先用份额变化/申赎估算；
- 融资余额上升 + 价格上涨可强化趋势，但极端杠杆化也增加反转风险。

**V1 结论**

- Evidence：B；
- Horizon：Tactical + Swing；
- 对中证1000、创业板、科创50的敏感度先验较高；
- 极端杠杆状态采用非线性函数，不无限加分。

---

## EQ13 — Market Breadth & Trading Liquidity｜市场广度与交易流动性

**定义**：上涨是否具有广度、市场是否容易成交、风险是否只集中在少数权重股。

**指标**

- 上涨/下跌家数；
- 新高/新低；
- 指数成份上涨比例；
- 等权 vs 市值加权收益差；
- 成交额；
- 换手率；
- Amihud 类价格冲击；
- 涨停/跌停广度；
- 指数内部横截面分散度。

中国市场资产定价研究表明流动性因子具有较强解释力，且流动性风险溢价在不确定性上升和系统性流动性收紧时扩大。[^24][^27]

**组合规则**

```text
成交放大 + 广度改善
→ 正向

成交放大 + 广度恶化 + 少数权重拉指数
→ 不视为全面风险偏好改善

缩量上涨
→ 弱确认

放量下跌 + 广度崩塌
→ 强负向
```

**V1 结论**

- Evidence：A/B；
- Horizon：Tactical；
- 小盘指数敏感度更高；
- 与 EQ14/EQ15 同属 Market State Group，必须设置组上限。

---

## EQ14 — Trend & Momentum｜趋势与动量

**定义**：价格自身包含的短期持续性和相对强弱信息。

**指标**

- 20D / 60D / 120D return；
- 均线结构；
- 距离高点/低点；
- 相对沪深300/全市场动量；
- 残差动量；
- 因子动量。

研究发现技术指标对中国股权风险溢价具有样本外预测力，且周频表现相对更明显；另有研究发现中国市场存在因子动量。[^28][^29] 但 A 股异常综述对普通“过去收益/规模”等类别的整体证据并不一致。[^11]

**V1 规则**

- 只做战术确认；
- Market State Group 总贡献必须封顶；
- 不允许“技术面强”覆盖高可信度、强负向盈利/信用基本面；
- 极端偏离均线时采用饱和函数，不能线性继续加分。

**V1 结论**

- Evidence：B；
- Horizon：Tactical；
- 不是结构性核心因子。

---

## EQ15 — Risk Appetite / Sentiment / Volatility｜风险偏好、情绪与波动

**定义**：投资者愿意承担风险的程度及其稳定性。

**指标**

- 已实现波动率；
- 最大回撤；
- 涨跌停与尾部风险；
- 波动率代理；
- 情绪指数；
- 融资行为；
- 横截面相关性和分散度。

近年中国市场研究显示情绪变化与流动性、波动之间存在显著关系，但这种关系具有公司和市场状态异质性。[^30]

**V1 规则**

- 情绪高 ≠ 基本面变好；
- 情绪极端高时不无限加分，应转为拥挤风险；
- 风险偏好只作为状态修正和小盘/成长风格轮动输入；
- 与 EQ13、EQ14 共用组上限。

**V1 结论**

- Evidence：B/C；
- Horizon：Tactical；
- 对中证1000/创业板/科创50敏感度高。

# 5. 黄金核心因子库

黄金不能用“A 股宽基同一套因子 + 一个黄金标签”。World Gold Council 的 Gold Return Attribution Model 将黄金驱动概括为经济扩张、风险与不确定性、机会成本（利率与汇率）和动量四类，适合作为上层分类框架。[^31]

V1 建议：

```text
机会成本
G01 美国实际利率
G02 美元
G03 美联储政策 surprise

风险
G04 风险与不确定性
G05 通胀状态

结构需求
G06 全球央行需求
G07 黄金ETF资金
G08 CFTC仓位与拥挤
G09 中国实物需求 / 上海金溢价
G10 供给与首饰/工业需求

人民币覆盖
G11 USD/CNY 换算

市场状态
G12 黄金趋势与动量
```

## G01 — US Real Yield｜美国实际利率

**定义**：持有无息黄金相对于真实无风险收益资产的机会成本。

**主要指标**

- 10Y TIPS real yield（FRED DFII10）；
- 5Y TIPS；
- 实际政策利率代理；
- 变化速度和 surprise。

FRED DFII10 为美联储 H.15 数据的日频 10 年期通胀保值国债实际收益率，可直接用于系统。[^32]

**V1 方向**

```text
实际利率下降 → 通常提高黄金吸引力 → factor_state > 0
实际利率上升 → 通常提高持有黄金机会成本 → factor_state < 0
```

但这一关系不是铁律。状态转换研究发现黄金和实际利率关系会随经济状态变化，甚至得到与简单负相关不同的结果。[^33] 近年的黄金表现也受到央行和亚洲需求等其他力量支撑。[^19]

**规则**

- 优先级 4/4；
- Evidence A/B；
- 强分值必须由 G02/G04/G07 等至少一类确认；
- 不允许“实际利率下降”单因子触发 90+ 黄金评分。

---

## G02 — USD｜美元

**定义**：美元汇率变化对以美元计价黄金价格和全球资金配置的影响。

**指标**

- DXY；
- 广义美元指数；
- 美元趋势 / surprise。

长期研究显示黄金与美元在样本中表现出较强对冲关系，但“美元风险的安全港”并不总是稳定成立。[^34]

**方向**

```text
USD 弱 → 黄金支持
USD 强 → 黄金压制
```

**规则**

- 优先级 4/4；
- Evidence A/B；
- 与 G01/G03 设置 `global_rates_fx` correlation group，避免 Fed → real yield → USD 三重计分。

---

## G03 — Fed Policy Surprise｜美联储政策 surprise

**定义**：美联储政策相对市场预期的意外程度，而不是政策利率绝对水平。

**事件**

- FOMC；
- 点阵图；
- 主席讲话；
- 资产负债表政策；
- 紧急政策。

**方向**

```text
超预期鸽派 → 黄金短期支持
超预期鹰派 → 黄金短期压制
```

**关键规则**

这是一个 **短寿命事件因子**。如果真实利率和美元已经充分反映政策变化，则 G03 的贡献应迅速衰减，防止重复计分。

**V1**

- 优先级 3；
- Evidence B；
- Half-life：1～3交易日（按事件类型配置）。

---

## G04 — Risk & Uncertainty｜风险与不确定性

**定义**：金融危机、地缘冲突、系统性尾部风险带来的避险/分散化需求。

学术研究发现黄金在部分主要发达市场极端下跌时期具有安全港属性，但国际证据并不普遍：一项覆盖1979–2009年的研究发现这一属性对大型新兴市场/BRIC 并不稳定。[^35][^36]

**工程含义**

禁止规则：

```text
A股大跌 → 黄金一定涨
```

允许规则：

```text
全球金融压力 / 地缘系统性风险上升
AND
黄金/美元/ETF等出现确认
→ G04 强正向
```

**冲击衰减**

地缘事件的安全港效应应有较快时间衰减；若风险事件没有升级，事件分应回落。

**V1**

- 优先级 3～4；
- Evidence A/B；
- Tactical 为主。

---

## G05 — Inflation Regime｜通胀状态

**定义**：通胀及通胀预期在政策可信度、实际利率与美元背景下对黄金的影响。

**禁止规则**

```text
CPI 上升 → 黄金 +3
```

World Gold Council 2026 年分析明确指出，高通胀本身不意味着黄金必然出现大行情；实际利率、美元、增长预期、亚洲需求与央行需求如何反应更重要。[^19]

**V1 条件规则**

```text
IF inflation_up
AND real_yield_down
AND (usd_weak OR policy_credibility_down OR recession_risk_up)
THEN strong_positive

IF inflation_up
AND real_yield_up
AND usd_strong
THEN neutral_to_negative

IF inflation_falls
AND real_yield_falls_fast
AND recession_risk_up
THEN gold can still be positive
```

**V1**

- 独立优先级 1；
- 条件触发后最高可升至 3；
- Evidence B/C。

---

## G06 — Central Bank Demand｜全球央行黄金需求

**定义**：官方储备机构对黄金的战略配置需求。

World Gold Council 2026 年央行调查显示，央行持有黄金的主要考虑包括长期价值储存、危机表现和分散化；调查同时显示央行对未来全球官方黄金储备增加仍有较高预期。[^37]

**规则**

- 这是 **战略/结构因子**，不是日频交易信号；
- 官方购金数据存在披露时滞和不完整性；
- 单月某央行暂停购买不能立即把结构因子反转为强负；
- 使用滚动3～12月官方净购金、调查和全球数据组合。

**V1**

- 优先级 2～3；
- Evidence B；
- Horizon Strategic；
- Update 月度/季度。

---

## G07 — Gold ETF Flow｜黄金 ETF 资金

**定义**：全球实物支持黄金 ETF 的持仓和资金变化。

World Gold Council 数据覆盖超过100只实物支持黄金 ETF，并提供周度与月度更新。[^38]

**方向**

- 持续净流入 / 持仓上升 → 投资需求确认；
- 持续净流出 → 投资需求减弱。

**注意**

ETF资金可能是价格上涨的推动因素，也可能是价格上涨后的跟随，不应声称单向因果。

**V1**

- 优先级 3；
- Evidence B；
- Horizon Tactical + Swing；
- 周度数据不得伪装成日频最新值。

---

## G08 — CFTC Positioning & Crowding｜CFTC 仓位与拥挤

**定义**：黄金期货中 Managed Money 等投机/机构仓位的变化与拥挤程度。

CFTC COT 数据反映每周二的持仓，通常在周五 15:30 ET 发布，因此天然存在约三天披露滞后。[^39]

**非线性规则**

```text
净多从中性区域持续改善
→ 正向确认

极端净多 + 价格远离趋势
→ 不继续加分
→ crowding_risk 上升

净多快速下降
→ 负向战术信号
```

**V1**

- 优先级 2；
- Evidence B/C；
- 必须保存 `observation_date` 与 `release_ts`，否则回测会产生前视偏差。

---

## G09 — China Physical / SGE Premium｜中国实物需求与上海金溢价

**定义**：上海市场相对国际黄金的本地需求、基差和交易活动。

**指标**

- 上海金基准价；
- Au99.99；
- 上海金相对折算伦敦/COMEX现货的溢价；
- 成交量；
- 交收；
- 中国黄金 ETF / 实物需求辅助。

上海黄金交易所提供每日行情和上海金基准价，适合作为人民币黄金本地覆盖层数据源。[^25][^26]

**规则**

- 正溢价扩大 + 成交/交收支持 → 本地需求增强；
- 价格换算必须做时区和交易时段对齐；
- 不把本地溢价直接加到全球金价核心因子。

**V1**

- 优先级 2；
- Evidence B/C；
- China overlay。

---

## G10 — Supply & Fabrication Demand｜供给与首饰/工业需求

**定义**：矿产供给、回收、首饰、科技等慢变量。

**规则**

- 作为战略背景；
- 高频行情通常不由供给单独解释；
- 高价可能抑制首饰需求并刺激回收，因此要非线性处理。

**V1**

- 优先级 1；
- Evidence C；
- Horizon Strategic；
- 不参与日内/隔夜强信号。

---

## G11 — USD/CNY Translation｜人民币汇率换算

**定义**：美元黄金转换成人民币黄金时的直接汇率覆盖。

**方向**

```text
USD/CNY ↑（人民币贬值）
→ 在美元金价不变时，人民币金价机械抬升
→ RMB Gold positive overlay

USD/CNY ↓
→ RMB Gold negative overlay
```

这是价格恒等关系层面的机制，因此 Evidence 可视为 A。

**关键规则**

- 只影响人民币黄金，不改变 Global Gold Core；
- Dashboard 应能解释“美元金价偏弱，但人民币黄金仍有支撑”的情形；
- 与 EQ09 的人民币因子共用数据，但资产语义不同，不混表。

**V1**

- 优先级 4（对人民币计价结果）；
- Evidence A。

---

## G12 — Gold Trend & Momentum｜黄金趋势与动量

**定义**：金价的短期趋势、追涨资金和均值回归风险。

World Gold Council 的黄金归因框架也将 momentum 作为核心主题之一。[^31]

**指标**

- 20D / 60D / 120D return；
- 距离长期均线；
- 新高/回撤；
- ETF/CFTC作为确认，不重复算。

**规则**

- 趋势正向可加分；
- 极端过热后边际贡献递减；
- 高拥挤 + 高动量时增加 reversal risk。

**V1**

- 优先级 2；
- Evidence B；
- Market State 类因素封顶。

# 7. 因子状态计算框架

## 7.1 连续数据统一标准化

推荐采用 robust normalization，而不是用固定绝对阈值适配所有年份。

示例：

$
z_t =
\frac{x_t-\text{rolling median}}
{1.4826 \times MAD}
$

再映射：

$
score_t = 100 \times \tanh(z_t / 2)
$

并裁剪到 `[-100,100]`。

优点：

- 对极端值更稳健；
- 不同指标可以统一进入状态层；
- 阈值随历史分布适应。

具体 rolling window 应按指标频率配置。

---

## 7.2 Level / Trend / Surprise / Event 四分量

推荐每个因子内部保留：

```yaml
state_components:
  level_score: -100..100
  trend_score: -100..100
  surprise_score: -100..100
  event_score: -100..100
```

### 宏观发布类 V1 模板

```text
FactorState =
45% Surprise
+ 35% Trend
+ 20% Level
```

### 市场连续类 V1 模板

```text
FactorState =
40% Trend
+ 30% Level
+ 30% Flow/Event
```

### 政策类

主要由 event engine 计算，后续逐步由已观测数据接管。

这些百分比是 V1 配置模板，必须支持回测修改。

# 8. 事件影响引擎

## 8.1 标准事件 Schema

```yaml
event_id: EVT_20260910_xxx
event_type: FED_POLICY
title: ...
source_tier: S
published_at: ...
effective_at: ...
ingest_at: ...

factor_ids:
  - G03_FED_POLICY_SURPRISE
  - G01_US_REAL_YIELD
  - EQ10_GLOBAL_FIN_CONDITIONS

direction: 1
strength: 4          # 1~5
confidence: 0.90
novelty: 0.85
priced_in: 0.30
implementation: 1.0

scope:
  geography: US
  market: global

asset_overrides: {}

horizon: tactical
half_life_days: 2

evidence_refs:
  - ...
```

---

## 8.2 事件影响公式

V1 推荐：

$
EventImpact =
sign
\times \frac{strength}{5}
\times sourceConfidence
\times novelty
\times (1-pricedIn)
\times implementation
\times Decay(age)
$

其中：

$
Decay(age)=
e^{-\ln(2)\cdot age/halfLife}
$

这样事件到达 `half_life` 后只剩一半影响。

---

## 8.3 priced-in 不得完全交给 LLM

LLM 可以输出：

```text
priced_in_estimate
reason
market_evidence
```

但最终值应由规则辅助：

- 事件是否已被一致预期；
- 利率/汇率/期货是否提前发生大幅变化；
- 公告是否只是确认已知信息；
- 市场价格在事件前后是否进一步反应。

若无法可靠判断，默认中性 `priced_in = 0.5` 并降低 Confidence，而不是让 LLM自信猜测。

# 9. 资产评分引擎

## 9.1 因子贡献

定义：

- \(F_i\)：因子状态，`[-100,100]`
- \(W_{a,i}\)：资产 a 对因子 i 的敏感度
- \(R_i\)：因子可靠度 `[0,1]`
- \(H_i\)：周期权重
- \(M_i\)：RegimeMultiplier，V1 默认 1.0，只留接口

$
C_{a,i}
=
W_{a,i}
\times F_i
\times R_i
\times H_i
\times M_i
$

方向分：

$
DirectionScore_a =
\frac{
\sum_i C_{a,i}
}{
\sum_i |W_{a,i}R_iH_iM_i|
}
$

理论范围约为 `[-100,+100]`。

Dashboard 分数：

$
AssetScore_a =
clip(50 + DirectionScore_a/2,0,100)
$

---

## 9.2 用户侧等级

| Asset Score | 标签 |
|---:|---|
| 80～100 | 强势偏积极 |
| 65～79 | 偏积极 |
| 45～64 | 中性 / 观察 |
| 30～44 | 偏谨慎 |
| 0～29 | 强风险警示 |

内部不要只存标签，必须存原始连续分数。

---

## 9.3 Missing Data 规则

缺失数据不能默认为 `0` 后假装“中性”。

正确做法：

```text
Factor unavailable
→ 从该次 numerator 和 denominator 中剔除
→ Coverage 降低
→ Confidence 下降
```

否则归一化会隐藏“系统今天其实没拿到关键数据”。

---

# 10. Confidence Engine

资产方向分和置信度必须分开。

V1 建议：

$
Confidence =
100 \times (
0.30 Coverage +
0.25 SourceQuality +
0.20 Agreement +
0.15 Stability +
0.10 ContextCertainty)
$

这是工程初始权重，不是统计估计结果。

## 10.1 各项解释

### Coverage

关键因子实际可用权重 / 应有关键因子权重。

### Source Quality

根据数据源 Tier、是否官方、是否存在备用源交叉验证。

### Agreement

高优先级因子是否方向一致。

### Stability

结论是否对单一指标/单一事件高度敏感。

### Context Certainty

V1 可主要由规则判断原因标签是否明确；V2 再接 Market Regime 模型。

---

## 10.2 V1 Confidence Gate

建议配置：

```text
coverage < 60%
→ confidence cap = 60

任一核心 A 级因子缺失
→ confidence cap = 70

事件只有单一 C 级来源
→ event confidence <= 50

D 级未验证消息
→ production contribution = 0

两个及以上高优先级因子强烈冲突
→ confidence -10~-15
→ label = "分歧环境"

超过 max_age
→ state = stale
→ 不按0分处理
```

# 12. 关键冲突与交互规则

## 12.1 A 股十条生产准则

### R-EQ-01：利率下降的“双义性”

```text
IF CGB_yield_down
AND growth_stable_or_up
THEN discount_support positive

IF CGB_yield_down_fast
AND growth_down
AND earnings_down
THEN discount_support contribution capped
AND risk flag = growth_scare
```

### R-EQ-02：人民币贬值不设固定正负号

必须先判定：

```text
usd_strength / trade_shock / capital_outflow /
policy_easing / export_reflation
```

再影响资产。

### R-EQ-03：成交放量必须和广度一起看

```text
turnover_up + breadth_up → risk-on
turnover_up + breadth_down → distribution / divergence
```

### R-EQ-04：政策“落地”比标题更重要

政策事件必须区分：

```text
传闻
表态
正式政策
预算/额度
执行
```

### R-EQ-05：估值只作为中长期支持

“历史低估值”不能触发短期强买入评分。

### R-EQ-06：宽松 + 弱信用时，小盘利好要封顶

若资金面宽松但私人信用/盈利持续恶化，不能按照“流动性高弹性”把中证1000/成长推到极高分。

### R-EQ-07：外资是确认项

外资活动不作为单因子追涨依据；且现行官方沪深股通披露无法提供旧式每日净流量。[^16]

### R-EQ-08：强经济也可能带来折现压力

```text
growth positive
discount_rate negative
```

允许同时存在，由评分自然抵消，不做硬覆盖。

### R-EQ-09：技术面上限

Market State Group 不得覆盖高可靠度的强负向盈利/信用状态。

### R-EQ-10：指数行业暴露动态化

任何“半导体政策利好科创50”“消费政策利好沪深300”等规则都必须乘以 **当前成份行业暴露系数**，不能永久写死。

---

## 12.2 黄金十条生产准则

### R-G-01：通胀不是直接多头规则

必须结合 real yield / USD / recession / policy credibility。[^19]

### R-G-02：实际利率是高优先级，不是必然关系

极端评分需其他因子确认，因为实证关系存在状态依赖。[^33]

### R-G-03：地缘冲击快速衰减

若事件不继续升级，G04 按 half-life 衰减。

### R-G-04：A 股单独下跌不等于全球黄金安全港成立

学术证据显示黄金安全港属性并非对大型新兴市场普遍成立。[^36]

### R-G-05：央行买金是战略因子

不允许一条央行月度新闻产生日频 +80 事件分。

### R-G-06：ETF 流是确认，不做单向因果

流入可以确认投资需求，但可能跟随价格。

### R-G-07：CFTC 极端多头进入拥挤模式

超过历史高分位后正向贡献递减，风险项增加。

### R-G-08：人民币黄金必须解释 FX

若：

```text
USD gold down
BUT USD/CNY up strongly
```

人民币黄金可以表现更稳，系统解释必须明确区分。

### R-G-09：Fed、real yield、USD 组内封顶

同一政策冲击不能三次满额计分。

### R-G-10：上海金溢价只影响 China overlay

不反向篡改 Global Gold Core。

# 14. Point-in-Time 与数据版本

这不是可选优化，而是 V1 必须设计。

每条宏观/低频数据至少保存：

```yaml
series_id: CN_M1_YOY
observation_date: 2026-08-31
release_ts: 2026-09-xxT...
ingest_ts: ...
effective_ts: ...
value: ...
revision_vintage: ...
is_preliminary: false
definition_version: M1_2025_REVISION
source_id: PBOC
```

回测：

```sql
SELECT latest_known_value
WHERE release_ts <= backtest_as_of
```

而不是：

```sql
SELECT latest_revised_history
```

否则会产生 look-ahead bias。

TradingAgents 参考项目在 2026 版本更新中专门加入了 FRED 等数据的 point-in-time / look-ahead 修复，这一工程经验应直接保留。

状态更新：自动

### 每日

- 市场价格；
- 国债收益率；
- 资金面；
- ETF；
- 融资；
- 市场广度；
- 技术状态；
- 新闻/政策事件；
- 黄金实际利率、美元、人民币、SGE行情。

### 每周

- 黄金 ETF；
- CFTC；
- 数据源可用性；
- 异常检测；
- 事件衰减清理。

### 每月

- PMI/CPI/PPI/工业利润；
- M1/M2/社融；
- 因子归因；
- 指数行业/风格暴露刷新。

### 指数调整 / 官方公告

立即触发：

- 成份更新；
- 行业暴露重算；
- methodology version 更新。

## 15.2 规则和权重生命周期

```text
candidate
   ↓
research
   ↓
shadow
   ↓
approved
   ↓
production
   ↓
deprecated
```

任何 LLM 新发现的因子默认：

```text

```

不得自动进入生产。

## 15.3 季度校准

建议每季度做：

- Direction hit rate；
- Rank IC / ICIR；
- T+1 / T+5 / T+20；
- 各评分区间未来收益分布；
- 因子边际贡献；
- 因子稳定性；
- 不同市场状态下的效果；
- Confidence calibration；
- 数据缺失敏感性；
- 评分换手率。

采用：

- expanding window；
- rolling / walk-forward；
- 时间序列前后切分。

禁止随机打乱时间进行 train/test。

## 15.4 调权原则

初期使用研究先验。

后续模型可以提出：

```text
old_weight = 3.0
proposed_weight = 3.6
evidence = ...
walk_forward_gain = ...
stability = ...
```

但：

- 默认单版本变化幅度设上限；
- 例如 ±25% 可作为初始治理阈值；
- 更大的权重变化需要人工审批；
- 每次生产变更生成 calibration report；
- 保留旧版本，可重放历史。

# 20. LLM 在准则体系中的边界

## LLM 可以做

```text
新闻去重
事件抽取
政策对象识别
事件 → 因子映射
原因标签识别
来源归并
冲突说明
证据摘要
用户解释
研究新因子候选
```

## LLM 不可以直接做

```text
随意修改 factor weight
随意创建生产因子
直接输出最终 AssetScore
忽略规则引擎 override
把传闻直接计分
用自然语言记忆覆盖结构化历史版本
```

### 推荐结构化输出

```json
{
  "event_type": "PBOC_POLICY",
  "verified": true,
  "source_tier": "S",
  "mapped_factors": [
    {
      "factor_id": "EQ01_CN_FUNDING_LIQUIDITY",
      "direction": 1,
      "strength": 3,
      "mapping_confidence": 0.91
    }
  ],
  "reason_tags": [
    "liquidity_easing"
  ],
  "unknowns": [
    "implementation_scale"
  ]
}
```

如果 `unknowns` 影响方向，就降低事件 Reliability，而不是让模型补全事实。

# 23. V1 上线验收条件

满足以下条件后，才建议称为“可用 V1”：

- 7 类目标资产都有稳定唯一 `asset_id`；
- 27 个核心因子都有结构化 definition；
- 每个生产因子都有至少一个真实数据源；
- A/B 级因子没有依赖未验证新闻；
- 宏观数据保存 `release_ts` 和 `vintage`；
- M1 等存在定义变化的序列保存 `definition_version`；
- 沪深股通没有使用已停止公开的每日北向净流量字段；
- 黄金 CFTC 使用发布日而非持仓观察日进行回测；
- 所有事件都有 decay；
- 所有相关因子都有 correlation group；
- 缺失数据会降低 Confidence；
- 评分结果可解释到 factor contribution；
- 每个资产至少能展示前三利多、前三利空与数据完整度；
- 权重、规则、Prompt、数据定义均有版本；
- 可以用 `as_of` 重放任意历史一天的判断；
- 至少完成一轮 walk-forward shadow evaluation；
- 生产分数不能由 LLM 自由生成。

# 24. 后续研究优先级

V1 完成后，最值得继续投入的研究并不是“增加更多新闻源”，而是以下四项：

1. **敏感度矩阵回测校准**：验证资金面、折现率、全球条件对大/中/小盘和成长指数的真实差异。
2. **Factor State 算法校准**：决定每个因子的 level/trend/surprise 组合和历史窗口。
3. **Regime 条件化**：研究流动性驱动、复苏、滞胀、风险厌恶等状态下因子权重是否应变化。
4. **Confidence 校准**：验证“高信心”是否真的对应更高的方向命中/更稳定的后验收益。

在这些验证完成之前，V1 的敏感度矩阵和阈值应明确标记：

> **Research Prior / Engineering Prior — Not Calibrated Coefficient**

## 附录：研究结论与待验证先验的边界

### 可以作为 V1 生产逻辑的内容

- 官方指数编制规则；
- 官方数据定义与发布时间；
- 数据版本 / point-in-time 约束；
- 事件来源可信度规则；
- 缺失值、时效、去重与衰减机制；
- 人民币黄金的汇率换算机制；
- “通胀不能单独决定黄金”“利率下降不能单独决定权益”等冲突规则；
- 因子证据分级；
- LLM 与确定性评分模块的职责边界。

### 必须进入回测校准的内容

- 15×6 A股敏感度矩阵具体数值；
- 各因子 level/trend/surprise 权重；
- `group_cap` 数值；
- Confidence 各项权重；
- Confidence cap；
- 事件 strength 映射；
- half-life；
- Tactical/Swing/Strategic 混合权重；
- Gold 各因子的相对权重；
- 分数档位与未来收益/风险之间的实际校准关系。

**V1 的正确目标不是一次性找到“永远正确的权重”，而是建立一个能够被证据、回测和版本治理持续更新的准则系统。**
