# WideGold V1 已知限制与后续方向

本文件用于明确“项目已完成什么”和“没有宣称完成什么”。停止继续追 Bug 并不代表所有外部依赖都已经达到长期生产 SLA。

## 1. Event Intelligence Live LLM

实机 Live Preview 中曾出现：

```text
llm_fallback_exhausted:extraction
```

同一轮分析里事件子任务失败被隔离，最终评分、Quality Gate 和 Preview 仍完成。这说明故障隔离有效，但也说明真实模型 endpoint / 模型参数 / Runtime Config 仍存在兼容性或稳定性风险。

当前版本不把“0 个事件”伪装成 Event Intelligence 完全成功。生产使用前建议进一步做 LLM Contract 测试、调用预算和失败率监控。

## 2. Fresh Coverage 与 Publish

最近一次实机真实 Preview 中，总体 weighted coverage 可以较高，但大量 FactorState 依赖短期 Last-Known-Good，fresh coverage 低于 50% Publish Floor。

系统行为：

```text
passed_for_preview = true
passed_for_publish = false
```

这是预期保护，不应该降低阈值来追求“成功发布”。

## 3. 盈利预测 Warm-up

`CN_INDEX_EARNINGS_REV` 使用免费当前一致预期并在 `external_bridge_data` 中积累本地历史快照。新安装不能凭空恢复过去 7 天的免费 snapshot，因此最初阶段可以 `WARM/UNAVAILABLE`。

删除 Docker Volume 会丢失这些积累。

## 4. 免费外资方向性数据

公开披露机制无法稳定提供旧式每日北向净流量。WideGold 不把成交额当成净流入，因此 `CN_FOREIGN_ACTIVITY` 在免费方案下可能处于 `UNAVAILABLE` 或低频更新。

## 5. 免费公网源

ChinaMoney、Eastmoney、WGC、指数公司等免费端点可能出现：

- 超时；
- HTML/XLS 结构变化；
- CDN/反爬；
- API 字段变化。

External Bridge 使用有界 retry、cache、negative backoff，并允许降级。它不是付费行情终端的 SLA 替代品。

## 6. 前端

V1 前端已形成完整 Dashboard/Admin 闭环，但代码仍集中在单个 React 入口文件。若继续扩展，建议拆分为 feature/page/component，增加 Vitest/Playwright。

## 7. Calibration

27 个因子的研究逻辑、敏感度和阈值是工程先验。虽然代码支持 Replay/Calibration 基础设施，但当前项目不宣称已完成长期样本的最终参数校准。

## 8. 数据许可

公开数据源能被技术访问，不等于允许所有商业使用方式。公开发布 GitHub 代码时只发布 Adapter，不发布抓取后的大规模第三方数据；实际部署者需要自行确认各来源条款。

## 9. 后续优先级

如果未来继续迭代，推荐顺序：

```text
LLM extraction 稳定性/成本
→ fresh provider coverage
→ point-in-time replay 数据完整性
→ sensitivity/calibration
→ automated decision review
→ regime detection
→ 前端模块化/浏览器测试
```
